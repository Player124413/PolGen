# 📱 APK-лаунчер PolGen

Нативное Android-приложение (одна активити, ~70 КБ), которое превращает
установку PolGen в «одну кнопку» — а всю установку показывает живым
журналом прямо в приложении.

Подходит для **всех 64-битных устройств с Android 7+** (arm64-v8a / x86_64).

## 📲 Установка

### Полная версия — со встроенным Termux

Собирается CI (см. [`../../ci/README.md`](../../ci/README.md)):
`PolGen-launcher-full.apk` содержит внутри официальный Termux APK.

1. Скачай `PolGen-launcher-full.apk` и открой на телефоне
   (разреши установку из неизвестных источников).
2. Открой приложение **PolGen** → кнопка **«1 · Установить Termux (встроен)»**
   → системное окно → «Установить». Termux ставится прямо из лаунчера,
   никуда ходить не нужно. Лаунчер сам откроет Termux для первичной
   настройки (~15 секунд).
3. Вернись в лаунчер → **«2 · Установить / обновить PolGen»** — в окне
   журнала построчно видно всё, что происходит: установка git, клонирование
   репозитория, Python, PyTorch, FFmpeg, загрузка моделей.
4. **«▶ · Запустить PolGen»** — сервер стартует, браузер с интерфейсом
   откроется сам.

### Лёгкая версия — без встроенного Termux (локальная сборка)

`PolGen-launcher.apk` (~70 КБ): кнопка «Установить Termux» открывает
F-Droid, дальше всё так же.

## 🖥️ Что видно в лаунчере

- статус Termux (найден / нет);
- строка обратной связи;
- **журнал установки** — моноширинный, с автопрокруткой: каждая строка
  вывода `install.sh` дублируется в приложение через `am broadcast`
  (скрипт в Termux шлёт broadcast `com.polgen.launcher.PROGRESS`,
  лаунчер принимает и дописывает);
- прогресс-бар на время выполнения задания;
- кнопка копирования команды (fallback, если Termux запрещает
  автозапуск — одна вставка, дальше всё автоматически).

## ⚙️ Как это работает

| Механизм | Описание |
|----------|----------|
| Встроенный Termux | `assets/termux.apk` (добавляется CI); установка через `PackageInstaller` API — системное окно подтверждения, без выхода из приложения |
| Живой прогресс | скрипт установки шлёт `am broadcast -a com.polgen.launcher.PROGRESS --es line "…"`; лаунчер ловит динамическим `BroadcastReceiver` и дописывает в журнал |
| `RUN_COMMAND` intent | Termux API: лаунчер отправляет bash-скрипт в `com.termux.app.RunCommandService`, тот открывает терминальную сессию |
| `allow-external-apps` | флаг Termux для внешних команд; установочный скрипт включает его сам при первом прогоне |
| Обновление | кнопка «Установить / обновить» делает `git pull` и переустанавливает зависимости |

## ❓ Один ручной шаг при самом первом запуске

Свежий Termux по умолчанию запрещает внешним приложениям запуск команд.
Если после «2 · Установить» журнал молчит — нажми «📋 Скопировать команду
установки», открой Termux и вставь её (долгое нажатие → Вставить). Скрипт
сам включит автозапуск — и **прогон установки всё равно будет виден в
журнале лаунчера**, а дальше все кнопки работают в один клик.

## 🔨 Сборка из исходников

Исходники — два smali-класса, манифест и иконки. Сборка не требует
Android SDK — только JRE и Python:

```bash
bash build.sh        # apktool (smali→dex, ресурсы) + sign.py (подпись v1)
```

Чтобы собрать версию со встроенным Termux локально, положи
`assets/termux.apk` (официальный universal-билд с
[releases Termux](https://github.com/termux/termux-app/releases)) перед
сборкой — или используй CI-workflow из [`ci/`](../../ci/README.md).

> [!IMPORTANT]
> `polgen-launcher-key.pem` — ключ подписи. Храни его: все обновления APK
> должны подписываться им же, иначе Android потребует удалить старую версию.
> Для публикации в Google Play понадобится v2-подпись и targetSdk 34
> (сейчас: v1 + targetSdk 29 для прямой установки).

## 📁 Файлы

```
PolGen-launcher.apk   — готовое подписанное приложение (лёгкая версия)
AndroidManifest.xml   — манифест (RUN_COMMAND, REQUEST_INSTALL_PACKAGES, иконка)
smali/…/MainActivity.smali          — вся логика (UI, PackageInstaller, RUN_COMMAND, журнал)
smali/…/MainActivity$ProgressReceiver.smali — приёмник прогресса из Termux
res/mipmap-*/         — иконки всех плотностей
assets/               — сюда CI кладёт termux.apk (встроенный Termux)
apktool.yml           — параметры сборки (minSdk 24 / targetSdk 29, versionCode 2)
build.sh              — скрипт сборки
sign.py               — v1-подпись на чистом Python (cryptography)
polgen-launcher-key.pem — ключ подписи (для будущих версий)
```
