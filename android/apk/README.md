# 📱 APK-лаунчер PolGen

Нативное Android-приложение (одна активити, ~70 КБ), которое превращает
установку PolGen в «одну кнопку»: ставит Termux при необходимости и
запускает полностью автоматическую установку PolGen внутри Termux.

Подходит для **всех 64-битных устройств с Android 7+** (arm64-v8a / x86_64).

## 📲 Установка

1. Скопируй `PolGen-launcher.apk` на телефон и открой его
   (разреши «Установку из неизвестных источников», если попросит).
2. Открой приложение **PolGen**.
3. Если Termux нет — нажми **«Шаг 1 · Установить Termux»** (откроется F-Droid),
   установи Termux и вернись в лаунчер.
4. Нажми **«🚀 Установить / обновить PolGen»** — в открывшемся окне Termux
   всё скачается и установится автоматически (Python, PyTorch, FFmpeg, модели).
5. После установки жми **«▶ Запустить PolGen»** — браузер с интерфейсом
   откроется сам.

> [!NOTE]
> Один-единственный ручной шаг может понадобиться при первом запуске:
> свежий Termux по умолчанию запрещает внешним приложениям запуск команд.
> Если после нажатия кнопки установка в Termux не началась — нажми
> **«📋 Скопировать команду установки»**, открой Termux и вставь команду
> (долгое нажатие → Вставить). Скрипт сам разрешит автозапуск — и дальше
> все кнопки лаунчера будут работать в один клик.

## ⚙️ Как это работает

| Механизм | Описание |
|----------|----------|
| `RUN_COMMAND` intent | Стандартный API Termux: лаунчер отправляет bash-скрипт в `com.termux.app.RunCommandService`, тот открывает терминальную сессию и выполняет его на глазах у пользователя |
| Разрешение `com.termux.permission.RUN_COMMAND` | Запрашивается системой при первом нажатии (dangerous-уровень) |
| `allow-external-apps` | Флаг в `~/.termux/termux.properties`; установочный скрипт включает его сам |
| Обновление | Кнопка «Установить / обновить» делает `git pull` и переустанавливает зависимости — можно жать после каждого апдейта PolGen |

Что делает установочный скрипт (виден в `smali/.../MainActivity.smali`):

1. включает `allow-external-apps` в настройках Termux;
2. ставит `git` (если нет);
3. клонирует репозиторий PolGen (ветка с Android-портом);
4. запускает `android/install.sh` — Python, PyTorch, NumPy, SciPy, FFmpeg,
   модели HuBERT/RMVPE, ярлык Termux:Widget.

## 🔨 Сборка из исходников

Исходники — один smali-класс (`smali/com/polgen/launcher/MainActivity.smali`),
манифест и иконки. Сборка не требует Android SDK — только JRE и Python:

```bash
bash build.sh        # apktool (smali→dex, ресурсы) + sign.py (подпись v1)
```

Подробности — в комментариях `build.sh` и `sign.py`.

> [!IMPORTANT]
> `polgen-launcher-key.pem` — ключ подписи. Храни его: все обновления APK
> должны подписываться им же, иначе Android потребует удалить старую версию.
> Для публикации в Google Play понадобится v2-подпись и targetSdk 34
> (сейчас: v1 + targetSdk 29 для прямой установки).

## 📁 Файлы

```
PolGen-launcher.apk   — готовое подписанное приложение
AndroidManifest.xml   — манифест (разрешение RUN_COMMAND, иконка, лаунчер-фильтр)
smali/…/MainActivity.smali — вся логика (UI, RUN_COMMAND, буфер обмена, fallback)
res/mipmap-*/         — иконки всех плотностей
apktool.yml           — параметры сборки (minSdk 24 / targetSdk 29)
build.sh              — скрипт сборки
sign.py               — v1-подпись на чистом Python (cryptography)
polgen-launcher-key.pem — ключ подписи (для будущих версий)
```
