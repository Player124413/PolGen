# 📱 PolGen для Android (Termux)

Полноценный порт PolGen на Android через **Termux**. Работает на всех 64-битных
телефонах и планшетах (arm64-v8a, x86_64): сервер крутится на устройстве,
интерфейс открывается в браузере — как обычное приложение.

Никакого root-доступа не требуется.

---

## 📋 Требования

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| Android | 7.0+ (64-бит) | 10+ |
| Архитектура | arm64-v8a или x86_64 | arm64-v8a |
| RAM | 4 ГБ (треки до ~1 мин) | 6–8 ГБ (треки 3+ мин) |
| Свободное место | ~3 ГБ | ~3 ГБ |
| Интернет | для установки и TTS | — |

> [!TIP]
> Скорость конвертации на телефоне: примерно **2–4 минуты на минуту аудио**
> (зависит от чипа). Прогресс виден в интерфейсе в реальном времени.

---

## 🚀 Установка

1. **Установите Termux** — только с [F-Droid](https://f-droid.org/packages/com.termux/)
   или из [GitHub Releases](https://github.com/termux/termux-app/releases)
   (версия из Google Play устарела и не работает).

2. **Скачайте PolGen в Termux**:

   ```bash
   pkg install git
   git clone https://github.com/Politrees/PolGen.git ~/PolGen
   cd ~/PolGen
   ```

   Либо распакуйте ZIP-архив релиза (`PolGen-x.x.x_Android.zip`) в домашнюю
   папку Termux и перейдите в неё.

3. **Запустите установщик**:

   ```bash
   bash android/install.sh
   ```

   Установщик сам:
   - проверит 64-битность устройства;
   - поставит Python, PyTorch (собранный для Termux), NumPy, SciPy, FFmpeg;
   - доустановит недостающие пакеты и скачает модели (HuBERT, RMVPE);
   - создаст ярлык **PolGen** для Termux:Widget (если установлен).

4. **Запустите**:

   ```bash
   bash android/run.sh
   ```

   Браузер с интерфейсом откроется автоматически. Если не открылся — зайдите
   вручную на `http://127.0.0.1:4000`.

> [!IMPORTANT]
> Держите Termux открытым во время конвертации. Отключите оптимизацию
> батареи для Termux (Настройки → Приложения → Termux → Батарея → Без
> ограничений), чтобы Android не убивал процесс в фоне.

## 🖥️ Интерфейс

Веб-интерфейс на русском языке, адаптирован под экран телефона:

- **Конвертация** — выбор голоса, загрузка аудио, ползунки транспонирования
  и похожести, прогресс конвертации в реальном времени;
- **TTS** — озвучка текста голосами Edge-TTS с последующей конвертацией;
- **Установка моделей** — ZIP-архив по ссылке или файлом с устройства;
- **Настройки** — пробуждение экрана (wake lock), очистка кэша моделей,
  управление готовыми результатами, шеринг в папку «Музыка».

Все результаты сохраняются в `~/PolGen/output/` и доступны через кнопку «Открыть».

---

## 🧠 Как это устроено

| Компонент | Назначение |
|-----------|------------|
| `android/server.py` | HTTP-сервер на чистой стандартной библиотеке Python (aiohttp/gradio в Termux не ставятся) + очередь задач |
| `android/static/index.html` | Одностраничный мобильный интерфейс |
| `android/install.sh` | Установщик зависимостей и моделей |
| `android/run.sh` | Запуск с wake-lock и ожиданием готовности порта |

Сервер использует те же оптимизированные ядра `rvc/`, что и десктопная
версия: адаптивные чанки по объёму памяти, кэш моделей, RMVPE-предиктор F0,
numpy-реализацию FAISS. Поэтому на телефоне доступны все возможности
десктопной версии, кроме CUDA-ускорения.

Переменные окружения (при желании переопределить):

```bash
POLGEN_HOST=127.0.0.1 POLGEN_PORT=4000 bash android/run.sh
```

## ❓ Частые вопросы

**Конвертация убивается системой на длинном треке.**
Android ограничивает фоновые процессы. Оставьте экран включённым, включите
wake lock в настройках приложения и отключите оптимизацию батареи для Termux.
На телефонах с 4 ГБ RAM обрабатывайте треки короче 1–2 минут.

**TTS выдаёт ошибку сети.**
Edge-TTS требует интернет. Проверьте, что сеть доступна, и повторите.

**PyTorch не устанавливается.**
Убедитесь, что Termux свежий (из F-Droid) и в репозитории есть пакет
`python-torch`: `pkg search python-torch`. Если пакета нет — обновите
репозитории: `pkg update`.

**Как открыть результат в галерее/плеере?**
Кнопка «Поделиться» в настройках копирует файл в `~/storage/music/PolGen`
(при первом использовании Termux запросит доступ к хранилищу).
